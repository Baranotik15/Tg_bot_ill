## Телеграм-бот ставок на события (aiogram)

Функционал:
- Регистрация пользователя при /start и выдача стартовых баллов
- Просмотр рейтинга пользователей по баллам (/top или кнопка)
- Ввод промокода, который начисляет баллы (/promo, /use CODE)
- Логи с ротацией по дням
- Ежечасный дамп базы данных (SQLite) в папку `dumps/`
- Админ-команды для управления событиями

### Установка
1. Установите Python 3.11+
2. Создайте и активируйте виртуальное окружение
3. Установите зависимости:
```bash
pip install -r requirements.txt
```

### Переменные окружения
Скопируйте `sample.env` в `.env` и заполните значения:
- `BOT_TOKEN`: токен бота от @BotFather
- `ADMIN_IDS`: список Telegram ID админов через запятую (например `123,456`)
- `INIT_POINTS`: стартовые баллы для новых пользователей (по умолчанию 1000)
- `DATABASE_URL`: `sqlite+aiosqlite:///./data/bot.db` (по умолчанию)
- `LOG_LEVEL`: `DEBUG|INFO|WARNING|ERROR|CRITICAL` (по умолчанию `INFO`)
- `LOG_DIR`: каталог логов (по умолчанию `./logs`)
- `DUMP_DIR`: каталог дампов (по умолчанию `./dumps`)

### Запуск
```bash
python -m bot.main
```

### Команды
- `/start` — регистрация/меню
- `🎰 Сделать ставку` или `/bet` — начать ставку
- `🏆 Рейтинг` или `/top` — топ пользователей по баллам
- `📊 Мой рейтинг` или `/me` - проверить свой рейтинг 
- `🎁 Промокод` или `/promo` — ввести промокод
- `/use CODE` — применить промокод напрямую

Админ-команды:
- `💳 Создать промокод` — применить промокод напрямую

### Примечания
- Дамп БД выполняется каждый час, файлы `db_YYYYmmdd_HHMMSS.sqlite` сохраняются в `dumps/`.
- Логи сохраняются в `logs/bot.log` с ротацией, хранится 7 последних файлов.
