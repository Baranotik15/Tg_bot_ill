# 🎭 Мафия: Telegram-бот со ставками

> *Добро пожаловать в темные улицы города, где решает не только удача, но и интуиция...*
Функционал:
> 
- 🎯 **Регистрация** при `/start` и выдача стартового капитала
- 🏆 **Рейтинговая система** — кто правит городом?
- 💰 **Промокоды** — секретные коды для пополнения счета
- 📊 **Ставки на события** — делай ставку, выбирай сторону
- 🔥 **Лимит времени** — 10 минут на ставку или упустишь шанс
- 📝 **Полное логирование** всех операций
- 💾 **Автоматические бэкапы** базы данных каждый час
- 👔 **Админ-панель** для крестных отцов

### Установка
### Требования
- Python 3.11+
- Docker (для контейнеризации)
- 
### Шаг 1: Клонирование и подготовка
```bash
git clone <your-repo>
cd <your-repo>
```
### Шаг 2: Виртуальное окружение
```bash
python -m venv .venv
```
```bash
source .venv/bin/activate  # Linux/Mac
```
или
```bash
.venv\Scripts\activate  # Windows
```

### Шаг 3: Установите зависимости:
```bash
pip install -r requirements.txt
```

### Шаг 4 Настрой переменные окружения
Скопируйте `sample.env` в `.env` и заполните значения:
- `BOT_TOKEN`: токен бота от @BotFather
- `ADMIN_IDS`: список Telegram ID админов через запятую (например `123,456`)
- `INIT_POINTS`: стартовые баллы для новых пользователей (по умолчанию 1000)
- `DATABASE_URL`: `sqlite+aiosqlite:///./data/bot.db` (по умолчанию)
- `LOG_LEVEL`: `DEBUG|INFO|WARNING|ERROR|CRITICAL` (по умолчанию `INFO`)
- `LOG_DIR`: каталог логов (по умолчанию `./logs`)
- `DUMP_DIR`: каталог дампов (по умолчанию `./dumps`)

### Шаг 5 Запуск локально
```bash
python -m bot.main
```

## 🔄 Восстановление базы данных из дампа внутри контейнера

### 1. Зайди в контейнер

```bash
docker exec -it tg_bot bash
```

### 2. Перейди в папку с дампами

```bash
cd /dumps
```
### Проверь список файлов:
```bash
ls -lh
```
### 3. Найди нужный дамп и перемести его в папку с активной базой
```bash
mv (Имя файла) /app/data/
```
### 4. Перейди в папку data
```bash
cd /app/data
```
### 5. Удали текущую базу данных
```bash
rm bot.db
```
### 6. Переименуй файл дампа в рабочее имя
```bash
mv (Имя файла) bot.db
```
### 7. Выйди и перезапусти контейнер
```bash
docker-compose up --build -d
```
## Миграции базы данных с Alembic при изменение кода базы данных

### 🔹 1. Инициализация Alembic

Если проект ещё не содержит Alembic в терминале пропишите:
```bash
alembic init migrations
```
Это создаст папку <b>migrations/</b> с <b>versions/</b> для файлов миграций.

Создаст <b>alembic.ini</b>, в котором указаны настройки базы.

<b>env.py</b> нужно подключить к твоим моделям:
измените переменные в файле ниже если его не было
### env.py
```bash
from bot.db import Base
target_metadata = Base.metadata


В alembic.ini укажи путь к базе SQLite:

sqlalchemy.url = sqlite:///./data/bot.db
```
Создайте папку где будет храниться база данных если её ещё нет:
```bash
mkdir -p data
```

### 🔹 2.  Первичная миграция

Если у тебя ещё нет базы или хочешь создать всё с нуля впиши в терминал:
```bash
alembic revision --autogenerate -m "initial"
```

Создаст файл в **migrations/versions/** с таблицами из моделей.

Проверь, что в **_upgrade()_** команды совпадают с твоими моделями.

### 🔹 3. Применяем миграцию:
```bash
alembic upgrade head
```
База создастся полностью.

✅ Если база уже есть и нужно просто синхронизировать Alembic, не трогая данные:
```bash
alembic stamp head
```
Помечает базу как уже имеющую последнюю версию миграции.

## Создание новых миграций 🏗️

Если ты вносишь изменения в модели (db.py) нужно будет сделать миграцию базы данных

Шаги следующие:

1. Создать новую миграцию с автогенерацией:

```
alembic revision --autogenerate -m "Короткое описание изменения"
```

2. Проверить файл миграции в **_migrations/versions/_**. 
Проверить, что миграция соответствует изменениям в моделях


3. Применить миграцию:
```bash
alembic upgrade head
``` 
## Откат миграций 🔙

Если нужно отменить последнюю миграцию:

-1 откатывает на одну версию назад.
```bash
alembic downgrade -1
```

Можно откатывать до конкретной версии указав ее название:
```bash
alembic downgrade 6bb2462d6477
```

## Примечания
- Дамп БД выполняется каждый час, файлы `db_YYYY_MM_DD_HH_MM_SS.sqlite` сохраняются в `dumps/`.
_______________________________
- Логи сохраняются в `logs/bot.log` с ротацией, хранится 7 последних файлов.
_______________________________
- Для добавления юзера в админы укажите его телегарм ID через запятую в переменных окружения .env
`ADMIN_IDS=222222222,111111111` все указаные тут айди будут считатсья админами и иметь функции админа
_______________________________
- При обновлении интерфейса добавлении пользователя как админа и тому подобное пользователю нужно будет
заново ввести команду /start
_______________________________
- По умолчанию ставки можно сделать в течение 10 минут после 
анонса события, для изменения этого параметра замените 
переменную `betting_end_time = now + timedelta(minutes=10)`
на необходимое время. Переменная находиться в файле `admin` 
функция `handle_event_creation`)
